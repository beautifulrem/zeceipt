NU7 activates on Zcash testnet on 2026-10-06 and on mainnet on 2026-11-05. This build refuses a transaction mined after activation, and says so by name, until the Zcash crates it uses support NU7; dossiers of transactions mined before then keep building and verifying. The sample customer's transactions were mined before activation, so the sample keeps working.

The funds' transactions

Find them with the key

The page reads compact blocks from a node and tries your key on each shielded output, here. The node learns which heights you read, not your key.

Recent blocks scan at about 1,000 a second, the 2022–23 spam blocks at about 30: start where the funds arrived, and use zeceipt dossier scan for long ranges.

Finding ids by hand

Open each transaction in your wallet's history and copy its id (64 characters, also called the txid). Most wallets export the history as a CSV file with the ids; zcash-devtool wallet list-tx prints them.

Control (optional)

Shows you can spend the funds now. From this wallet, send any small amount to your own address with the reviewer's nonce as the memo, wait for it to be mined, then enter both. With no reviewer's nonce, answer a beacon: the latest block's hash.

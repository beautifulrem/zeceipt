      What this does not prove

        Challenge the holder

        A dossier's origin, path and deposit claims show what the holder's funds did. To see that they can spend them now, send them a fresh nonce and ask for a control claim that answers it.

        Your nonce

        1. Send the holder this nonce.
        2. From the wallet that holds the funds, they send any amount (the smallest will do) to their own address, with the nonce as the memo. The transaction must spend notes the dossier discloses.
        3. They add that transaction to their dossier as the control claim (on the Build page: the nonce and the challenge transaction's id), and send you the new dossier.
        4. Open it here: the control claim must verify and answer this nonce.

        While a nonce is in this page, a control claim that answers any other nonce fails. The nonce is kept in this page's memory only: reloading or closing the page forgets it, so note it in your case file.

        Privacy: this page asks a public node for each transaction the dossier names, only when you check one, and sends nothing else. The node learns which transactions you looked up. The page stores nothing.

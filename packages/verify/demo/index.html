Zeceipt verifier

Private outside, provable per payment. Verification runs entirely in this page (WebAssembly). The raw transaction is fetched from the source you choose; the receipt's outgoing cipher key never leaves this page.

1. The receipt

2. The transaction

Fetching uses the txid inside the receipt: the node learns which txid you asked for. A file keeps you offline.

3. Verify

What a valid result proves

  • The named transaction pays the shown value to the shown recipient with the shown memo (recovered cryptographically from the chain data with the disclosed per-output key).
  • If signed: the holder of the shown issuer public key produced this receipt. Binding that key to an organisation is a separate step.

What it does not prove

  • Who is showing you the receipt (use a challenge for that).
  • That the output is still unspent, or that whoever shows you the receipt can spend it (a receipt carries no spending ability).
  • Anything about other outputs, other transactions, or balances.
  • This page requests only the raw transaction; if you fetch it from a public node, that node learns which txid you looked at.
